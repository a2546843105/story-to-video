# 并行制作

## 推荐分工

主代理负责：

- 开工前置检查和 API/音色参数确认；
- 音频、时间轴与分镜清单；
- 风格锚点和人物白名单；
- 白边流程和共享版式变量；
- 三个代表镜头；
- 合并、全片质检、渲染和交付。

三个制作代理分别负责连续场景范围，例如：

- A：scene-002 到 scene-014；
- B：scene-015 到 scene-027；
- C：scene-028 到 scene-039。

保留开头、代表中段和结尾给主代理或提前完成，不重复写文件。

## 派工硬门槛

满足以下条件前不得派工：

- `preflight.status` 已批准，所需 API 凭据已确认可用；
- 最终旁白和带时间戳的场景清单已锁定；
- 风格锚点、豆包母图和人物白名单已锁定；
- 2 px 白边生成、内裁 1 px 和深浅底检查已通过；
- 人物高度、40 px 分区间距和底部 170 px 字幕区已写成共享变量；
- 代表镜头已覆盖单人物、多人同框、人物加 UI/卡片，并由主代理人工通过。

不要为了抢时间提前派工。规范未冻结时的并行会把一个问题复制到所有场景。

## 为什么按连续范围分

每个代理同时完成自己范围的素材、场景、动画和联系表，减少等待与交接。不要把“生图、裁图、时间轴”拆成三条互相等待的流水线。

## 派工模板

向每个代理提供：

```text
负责 scene-XXX 至 scene-YYY，只修改这些场景及自己的 assets/generated/<range>/ 和 snapshots/<range>/。

必须读取：
1. frame.md / MOTION.md
2. scene_manifest.json 中自己的范围
3. character-whitelist.txt
4. 已批准的代表镜头
5. 共享版式变量和白边规范

硬规则：
- 豆包每次出现都引用 doubao-mother.png，禁止重新设计脸、发型或主体服装语言；
- 其他人物参考母图的画风即可，身份不要求跨作品固定；
- 固定人物只引用白名单素材；
- 透明人物保留约 1 px 干净白边，禁止红紫色残边；
- 1920×1080 下主人物通常占画面高度 45–55%，配角通常占 38–50%；
- 独立人物区域至少相隔 40 px，人物、气泡、UI 和关键信息不得互压；
- 底部170px不放主体或气泡；
- 气泡不写名字、不遮脸、尾巴指向说话者；
- 对话不复述旁白；
- 每幕必须有进入、反应、停留；
- 完成后生成联系表并自行检查残肢、串样和重叠。

交付：
- 场景文件；
- 生成/裁剪素材；
- 包含深浅底边缘检查的联系表；
- 自检结果和未解决问题。
```

## 合并门槛

收到范围交付后：

1. 先看联系表；
2. 再运行场景范围检查；
3. 只合并通过的范围；
4. 系统性问题退回模板，不在主时间轴上逐帧补救。

## 时间预算

同一画风和人物已锁定时，一个代理处理约12–14幕应控制在45–75分钟。主代理并行做音频、清单和集成，整片目标2–3小时。
