# 交付预设

## 默认平台上传版

- 容器：MP4
- 视频：H.264 High、`yuv420p`
- 画面：1920×1080、30fps、BT.709
- 编码：x264 `preset slow`、`CRF 21`
- 峰值约束：`maxrate 5M`、`bufsize 10M`
- 关键帧：每 2 秒，`g=60`
- 音频：AAC、48kHz、160kbps
- 播放：`faststart`
- 整体响度：约 `-16 LUFS`，不高于 `-1 dBTP`

使用：

```bash
node scripts/encode-platform.mjs <input.mp4> <output.mp4>
```

## 文件仍偏大

依次尝试：

1. 把 CRF 从 21 调到 22；
2. 把峰值从 5M 调到 4M；
3. 抽查细线、文字、图表、颗粒和转场；
4. 没有视觉抽查，不直接超过 CRF 23。

只有用户明确要求归档母版时才额外输出高码率版本。

## 验证

- 时长与最终音频及时间轴一致；
- 1920×1080、30fps；
- H.264 + AAC；
- 音画同步、无黑帧、闪烁和明显块状压缩；
- 文件明显小于高码率渲染版本；
- 输出文件非空且可播放。
